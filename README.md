# Mak Sri Kitchen 🍗✨

Website resmi dan link-in-bio untuk **Mak Sri Kitchen** — Warung Spesial Olahan Ayam & Aneka Menu Chinese Food Halal khas Mak Sri Kitchen, Umbulharjo, Yogyakarta.

## 🌟 Fitur Utama
- **Landing Page Interaktif (`index.html`)**:
  - Hero Section dengan CTA pemesanan cepat via WhatsApp.
  - Menu lengkap 28 olahan ayam (Lauk Tumis/Saus, Ayam Goreng Spesial, Kulit Ayam Crispy, Nasi & Sup Ayam) dengan fitur filter kategori dan live search.
  - Review pelanggan, cerita warung, FAQ interaktif, dan embed Google Maps live ke lokasi resto di Jl. Veteran, Umbulharjo, Yogyakarta.
- **Link-in-Bio (`/link`)**:
  - Halaman bio link mobile-first yang terhubung langsung ke WhatsApp, ShopeeFood, GoFood, GrabFood, Google Maps, dan Instagram (@maksrikitchen).
- **Desain Modern & Responsif**:
  - Warm food color palette (Golden Crisp `#F07810`, Chili Red `#E03131`).
  - Tipografi Google Fonts modern (Fredoka & Nunito).

## 🚀 Menjalankan Secara Lokal
```bash
# Menggunakan serve atau static web server apa saja
npx serve -l 3000
```
Buka browser pada `http://localhost:3000` untuk website utama dan `http://localhost:3000/link` untuk link-in-bio.
